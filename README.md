# 盘中哨兵 · Windows 电脑版

A 股自选股盘中提醒工具，包含多源行情、迷你置顶盯盘窗、个股技术分析、资讯雷达和可选的资讯关联 Agent。

**只读行情，不连接券商，不自动下单。** 这是可运行的 Python 源码版，不是免安装 EXE；行情和资讯基础功能不需要 API 密钥。

## 一键启动

需要 Windows 10/11、Python 3.10+（带 Tcl/Tk，安装时勾选 Add Python to PATH）以及网络连接。

1. 下载或克隆本仓库并解压，进入含 `start.cmd` 的目录。
2. 双击 **`start.cmd`**。
3. 首次启动会创建虚拟环境、安装依赖、从示例生成个人配置，并打开网页控制台和置顶盯盘窗。
4. 在网页中修改示例自选股和成本线，保存后点击“启动监控”。

本机控制台地址：<http://127.0.0.1:8765/>。保持启动窗口运行；关闭它会结束其启动的后台。重复启动会复用已有控制台，不覆盖个人配置。

日常修改监控规则的流程：**停止监控 → 编辑并保存 → 重新启动监控**。首次附带的股票和成本值仅为演示，不是推荐或真实持仓。

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 多源行情 | 腾讯、东方财富、新浪并发取数，显示各路状态，单路失败时降级 |
| 个股提醒 | 开板、炸板、回封、快速拉升/下跌、分时均价/成本/MA5 穿越；每只股票可单独选择 |
| 置顶小窗 | 紧凑多股显示、涨跌幅突出、悬停分时图、关键事件高亮、最小化 |
| 技术分析 | MA、MACD、RSI、布林带、ATR、20 日通道和关键价位；自动计算动态 MA5 |
| 资讯雷达 | 同花顺、东方财富、雪球等热榜和财经快讯，关键词与自选股匹配 |
| 资讯 Agent | 用户自行配置兼容 API，分析新闻与股票/板块的可能关联，需自行承担 API 费用 |
| 可选手机连接 | 电脑作为后台，经 Tailscale 私有 HTTPS 访问；自选、状态、提醒和最近分析结果共享 |

“20 秒涨跌超过 3%”是默认快速波动规则，时间窗口和阈值可调整。免费源轮询不等于交易所逐笔实时行情，不能保证捕获每次瞬时变化。

## 常用启动方式

```powershell
# 正常启动：网页 + 置顶窗
.\run.ps1

# 只用网页，不启动置顶窗
.\run.ps1 -NoWidget

# 只完成初始化与配置校验
.\run.ps1 -SetupOnly

# 不自动打开浏览器
.\run.ps1 -NoBrowser

# 命令行单次检查
.\run.ps1 -Once -PrintQuotes -NoNotify
```

PowerShell 提示脚本执行策略时，可以直接双击 `start.cmd`；启动器只为该次脚本执行设置策略，不修改系统永久策略。

手机连接属于可选功能，不影响纯电脑版使用。**不要把 8765/8766 转发到公网**。配置方式见[手机与安全远程连接](docs/REMOTE_ACCESS.md)。

## 测试

初始化依赖后执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

前端逻辑测试需要 Node.js 18+；Node.js **不是日常运行依赖**：

```powershell
node --test tests/frontend.test.cjs
node --check web/app.js
```

当前整理基线包含 64 项 Python 测试和 5 项前端测试。离线测试通过不代表外部免费数据接口始终可用。

## 个人数据与使用边界

仓库只包含示例配置，个人 `config.json`、`data/`、API 密钥、Tailscale 账号与地址、数据库、日志和虚拟环境均不应提交。

普通监控数据保存在电脑；主动运行资讯 Agent 时，新闻标题、热榜条目与启用的自选股代码/名称/成本会发送到用户配置的 API。请在使用前确认该服务的数据处理规则。

免费接口可能延迟、限频、缺失或变更，软件不承诺行情完整性或商业数据授权。技术评分和新闻关联属于辅助分析，不是买卖建议。电脑休眠或退出后台后不能继续提醒；手机网页锁屏/后台不保证及时提醒。
