# A 股自选股多源实时提醒器

一个独立、只读行情的盘中提醒工具。它会并发请求腾讯、东方财富、新浪三路免费行情，对自选股检测：

- 封板后的开板预警、炸板和回封
- 跌破/收复分时均价线
- 跌破/收复个人持仓成本线
- 跌破/收复自动计算或手工配置的 MA5 价格线
- 20 秒内涨跌超过 3% 的快速拉升或快速下跌（窗口和阈值可调）
- 自选股个股技术分析：均线、MACD、RSI、布林带、ATR、20 日通道与关键价位

程序只提醒，不连接券商、不下单。

## 最快启动方式（Windows）

解压后直接双击 `start.cmd`：

1. 自动寻找 Python 3。
2. 首次运行自动创建 `.venv` 虚拟环境。
3. 缺少依赖时自动安装。
4. 首次生成 `config.json`。
5. 自动打开本机可视化控制台。

首次打开会显示示例股票，可在网页内添加、删除或修改成本线，MA5 默认自动计算；保存后点击“启动监控”。以后再次双击会直接打开界面并启动盘中监控，不会覆盖已有配置。

## 可视化控制台

界面运行在 `http://127.0.0.1:8765`，只监听本机，不会把配置上传到外部服务器。它提供：

- 一键启动、停止和手动刷新行情。
- 三路数据源在线状态、延迟和返回数量。
- 多源聚合价格、涨跌幅、分时均价、成本线、自动 MA5 和封板状态。
- 每只股票可单独选择开板预警、炸板、回封、快速拉升、快速下跌、分时均价、成本线和 MA5 八类监控项目；没有勾选的项目不会生成提醒。
- 点击每只股票右侧“分析”，打开多源复权日线技术分析面板。
- 网页内管理自选股、悬浮窗显示名单、快速波动阈值、轮询频率、确认规则和提示音。
- 查看 SQLite 中保存的最近提醒。

关闭启动窗口会同时关闭本地控制台。重复双击启动器时，如果控制台已经运行，会直接打开已有页面。

## 资讯雷达

控制台顶部新增“资讯雷达”模块，用来把市场消息和自选股放在同一个工作台里：

- 默认并发获取同花顺热榜、东方财富人气榜、雪球热股、财联社热门、华尔街见闻最热/最新、金十数据、格隆汇、MKT 新闻和快讯通。
- 雷达设置中提供 26 个可选平台，包含炒股软件热股榜、财经、快讯、综合新闻、热榜和科技社区；单个平台失败不会遮住其他来源。
- 同花顺热榜展示热度、涨跌幅和热榜标签；东方财富人气榜展示现价、涨跌幅和人气排名，均可直接打开个股详情页。
- 自动用自选股代码、已配置或实时行情识别出的股票名称匹配标题，并用红色“自选”标签突出显示。
- 支持最多 40 个自定义关键词，命中后用黄色标签标记；可一键切换“只看与我相关”。
- 支持标题搜索、平台筛选、30–1800 秒自动刷新和 5–50 条/平台的数量控制。
- 后端带有内存缓存，前端反复切换模块不会重复请求免费接口；点击“立即扫描”才会强制更新。

资讯由免费公开聚合接口提供，不需要密钥。免费接口可能缓存、限流或改变协议，因此页面会分别显示各个平台的在线状态、延迟和条数；它适合热点发现和盘面辅助观察，不应被当作公告原文或交易依据。

### 资讯关联 Agent

资讯雷达内置一个可选的“资讯关联 Agent”，用于把当前筛选出的新闻、同花顺/东方财富/雪球热榜股票以及本地自选股整理成一份关联分析：

- 新闻可能关联哪些 A 股个股和行业/题材板块，并给出利好、利空或中性的方向判断。
- 当前热榜股票与哪些已获取新闻存在基本面、产业链、主题或市场情绪关联。
- 哪些新闻可能影响本地自选股，并明确列出证据新闻 ID、关联理由和置信度。
- 支持用户在每次分析前追加问题，例如只看机器人、医药或地产方向。

点击“API 设置”填写兼容的 Chat Completions 完整地址、模型和 API 密钥；也支持以 `/responses` 结尾的 Responses 接口，以及不需要密钥的本地兼容服务。软件不内置模型密钥；未配置 API 时，免费资讯雷达仍可正常使用，只是 Agent 分析按钮会提示先完成设置。

API 密钥只保存在本机 `data/news-agent.json`，后端返回给网页的设置中不包含密钥原文，发布压缩包也排除整个 `data` 目录。运行分析时，当前筛选新闻的标题/来源/时间、热榜条目和启用的自选股代码/名称/成本会发送给你填写的 API 地址；不会发送行情数据库、提醒历史或其他本机文件。若使用收费模型，调用费用和数据处理规则由对应 API 服务商决定。

当前免费资讯源主要提供标题和热榜字段，因此 Agent 做的是“标题级关联推断”，不是事实因果证明。系统提示会要求模型禁止捏造新闻或股票代码，但输出仍可能出错；重要结论应回到公告原文、交易所披露或权威媒体核实，也不应据此自动交易。

## 迷你置顶盯盘窗

双击 `start.cmd` 时会同时启动一个无边框、半透明的迷你悬浮窗，也可以单独双击 `widget.cmd`。它会：

- 始终显示在其他窗口上方，每只股票只占一行，可按住鼠标左键拖动。
- 顶部“—”按钮可最小化到 Windows 任务栏；从任务栏恢复后会自动回到无边框置顶状态。
- 同时显示多只股票，不显示股票代码；涨跌幅使用更大的字号，当前价作为次要信息。
- 在网页自选表格的“悬浮”列控制哪些股票进入小窗口，最多直接显示 10 只。
- 优先提示封板、开板、成本线下、MA5 下和均价线下等状态。
- 出现炸板、开板或 20 秒内超过 3% 的快速拉升/下跌时，窗口立即提到最前，相关股票临时排到第一行并轻微闪烁高亮。
- 鼠标悬停在任意一行后展开该股票当天分时走势；滚轮可以切换走势图股票。
- 分时走势同时获取腾讯 1 分钟线和新浪 5 分钟线，单路失败时自动降级。
- 右键可切换股票、打开完整控制台或关闭悬浮窗。

悬浮窗使用单实例保护，重复启动不会叠加多个窗口。如不希望随控制台自动启动，可使用：

```powershell
.\run.ps1 -NoWidget
```

## 多源策略

每轮同时发起三路请求，单路异常不会中断：

1. 每个数据源分别保存连续状态。任一新鲜数据源出现“封板 → 开板”跃迁，就立即提醒，避免中位价掩盖短暂炸板。
2. 跌破均价/成本/MA5 默认要求两个数据源连续两轮确认。
3. 只剩一个数据源时可降级提醒，事件会标为 `single-source`。
4. 展示价格使用多源中位数，降低单源异常值影响。
5. SQLite 保存状态和事件，程序重启不会把当天旧状态反复当成新事件。

免费网页接口没有服务等级保证，可能限流、变更或短时不可用。多源能降低漏报概率，但无法保证捕获发生并恢复于一个轮询周期内的亚秒级开板。

## 个股技术分析

自选表格每行右侧提供“分析”按钮。面板并发请求腾讯、东方财富、新浪三路历史日线，并把本轮实时价格并入最后一根 K 线；历史结果缓存 5 分钟，不会因反复打开面板而高频请求。

当前纳入的指标是这套盘中提醒器最适合、且只依赖价格日线即可稳定计算的一组：

- 趋势：MA5、MA10、MA20、MA60，MA20 五日斜率与均线排列。
- 动量：MACD(12,26,9)、RSI(14)，并识别交叉和极值区。
- 波动：布林带(20,2)、ATR(14)、NATR 与 20 日收益波动率。
- 突破：以前 20 个完成交易日的最高/最低价作为唐奇安通道，避免把当日高低点误算进突破基准。
- 关键线：分时均价、用户成本、各周期均线、布林轨道和 20 日高低点。
- 综合结果：给出 -100～+100 的“技术强弱评分”、证据信号和风险项。评分只描述当前技术状态，不是收益概率，也不是买卖建议。

腾讯走专用前复权 K 线；新浪原始日线会结合其复权因子转换为同口径前复权序列，两路逐日交叉后取中位数。东方财富作为第三条并发链路，失效时自动降级，不阻断分析。面板会明确显示每一路成功/失败、参与计算的来源、日线数量和是否前复权。

## 安装

需要 Python 3.10 或更高版本：

```powershell
cd C:\path\to\stock-alert
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.example.json config.json
```

编辑 `config.json`，至少修改 `stocks`。然后启动：

```powershell
.\.venv\Scripts\python.exe main.py --config config.json
```

也可以直接运行 PowerShell 启动器：

```powershell
.\run.ps1
```

PowerShell 启动器还支持：

```powershell
.\run.ps1 -Once -NoNotify       # 单次联网检查，不发通知

.\run.ps1 -NoWidget             # 不启动迷你置顶盯盘窗
```

## 自选股配置

```json
{
  "code": "600000",
  "name": "浦发银行",
  "cost": 9.20,
  "ma5": 9.10,
  "auto_ma5": true,
  "widget_enabled": true,
  "limit_pct": 0.10,
  "enabled": true
}
```

- `code`：必填，六位 A 股代码，也接受 `sh600000`、`600000.SH`。
- `name`：可选；为空时采用行情名称。
- `cost`：可选，个人持仓成本价。
- `auto_ma5`：默认 `true`。从腾讯、新浪和东方财富读取前复权历史日线，以“当前实时价 + 前 4 个完成交易日收盘价”动态计算 MA5。
- `ma5`：可选的手工/备用 MA5；关闭自动计算时直接使用，历史日线同时失败时作为回退值。
- `widget_enabled`：是否在迷你置顶盯盘窗中显示，默认 `true`，也可直接在网页“悬浮”列切换。
- `monitor_items`：该股票启用的监控项目列表。旧配置缺少此字段时自动启用全部八项；网页“监控项目”按钮可逐股修改。
- `limit_pct`：可选，涨跌幅限制，例如主板 `0.10`。供应商返回涨停价时优先使用供应商值。
- `enabled`：是否监控。

自 2026-07-06 起，沪深主板风险警示（ST / *ST）股票的默认回退比例按 10% 处理。新股上市初期、退市整理等特殊证券的涨跌幅制度仍可能不同，务必优先采用行情源涨停价，必要时填写正确的 `limit_pct`。

## 自动 MA5

动态 MA5 每轮随实时价更新：

```text
动态 MA5 =（当前实时价 + 前 4 个已完成交易日收盘价）/ 5
```

历史收盘价由腾讯、新浪和东方财富前复权日线并发获取，同一日期取可用来源的中位数，并按股票和交易日缓存，不会每 2 秒重复请求历史接口。任一路历史接口失败时其余来源继续工作。界面中的 MA5 单元格会显示“自动”及历史来源；将“自动”取消勾选后，改用手工值。

## 分时均价

程序从各源的累计成交额和累计成交股数计算：

```text
分时均价 = 累计成交额 / 累计成交股数
```

腾讯和东财成交量按“手”返回，解析器会统一转换成股；新浪直接返回股。多源分别计算均价后再确认穿越。

# 手机安全连接与双端同步

现已支持电脑作为唯一后台，手机通过 **Tailscale 私有 HTTPS 网页**使用。此版本不是 APK，不需要租云服务器，也不要把 8765/8766 端口转发到公网。

## 首次连接

1. 电脑双击 `start.cmd`，让控制台保持运行。旧版后台需要关闭后重新启动，直接刷新网页不能升级 Python 后台。
2. 电脑安装 [官方 Tailscale](https://tailscale.com/download/windows)，然后双击本目录的 `remote.cmd`。
3. 按向导完成 Tailscale 登录、Serve / HTTPS 授权。HTTPS 证书中的设备域名会进入公开证书透明度日志，但软件页面不公开。向导只配置私有 Serve，**不配置公网 Funnel**。授权等待超时后，再次运行 `remote.cmd` 即可。
4. 手机安装 [官方 Android Tailscale](https://tailscale.com/download/android)，登录与电脑相同的账号，开启连接。
5. 在电脑控制台点击“手机连接”，复制生成的 `https://设备名.网络名.ts.net` 地址，在手机浏览器打开。可从浏览器菜单添加到主屏幕。

首次成功配置后，日常启动仍用 `start.cmd`。Tailscale 后台保存私有代理配置，手机使用同一地址；不要改成 `http://电脑IP:8765`。电脑休眠、关机、断网或软件退出后，手机不能继续取数。

## 可以同步什么

- 自选股票、成本 / MA5 / 个股监控项目、电脑悬浮窗显示选择。保存到电脑后，另一端页面通常约 3 秒内同步；暂停在后台的页面回到前台时重新同步。
- 监控启停状态、行情快照和提醒历史。手机与电脑共用一个监控线程，不为每台手机重复向行情源轮询。
- 最近一次资讯 Agent 分析结果，保存在电脑 `data/news-agent-result.json`，重启后仍可查看。两端同时提交分析时只接受一个，避免重复 API 消耗；点击分析仍会调用用户配置的 API，并可能产生服务商费用。
- 手机股票列表自动改为卡片，突出涨跌幅，保留监控项目编辑、个股分析和资讯雷达。

**保存流程：停止监控 → 修改并保存 → 重新启动监控。** 启停在所有设备上同时生效。运行中的监控规则不自动热替换。

每份配置附带版本号；若另一端先保存，本页面再次保存会收到冲突提示，不会静默覆盖。先记下本页需要保留的改动，再点击“载入最新配置”重新编辑。未保存的草稿不跨设备同步。资讯雷达设置也有版本校验。

## 安全边界与关闭方法

- 本机管理入口只监听 `127.0.0.1:8765`；远程专用入口只监听 `127.0.0.1:8766`，Tailscale Serve 将私有 HTTPS 转发到后者。
- 远程每个请求都检查 Serve 注入的用户身份，只允许配置时电脑所属账号；同一网络内其他账号、匿名请求、Funnel 请求均不获软件授权。带标签的设备不支持此身份流程。
- 写请求要求来自准确的私有 HTTPS Origin；本机入口检查 Host / Origin，拒绝将 Tailscale 代理误接到本机管理端口。
- 手机不能查看 / 修改 Agent API 设置、webhook 推送地址、本地文件路径，也不能修改远程授权。密钥继续只保存在电脑。手机可以主动调用已配置的 Agent 并查看结果。
- 这不是防御本机恶意程序的沙箱：本机管理员或恶意进程可能伪造本机代理头。不要将本地管理端口另行转发，不要共享 Tailscale 账号；建议为账号开启多因素认证、移除丢失的设备。
- 在电脑“手机连接”中点击“关闭远程授权”，软件立即拒绝手机后续请求，本机不受影响。此按钮保留 Tailscale 的空代理入口；要一并移除本软件的代理，可在项目终端运行 `.\.venv\Scripts\python.exe remote.py disable`。
- 向导遇到其他已有 Serve/Funnel 配置会拒绝覆盖，避免影响其他服务。远程 8766 被占用时只禁用远程监听，本机继续运行。
- `data/remote-access.json`、`data/news-agent-result.json`、个人 `config.json` 与所有 `data/` 文件均不进入发布压缩包。

手机网页处于后台或锁屏时不能保证及时提醒，本版**没有安卓后台常驻 / 系统推送**。免费行情源仍可能延迟、限频和缺失；加密远程连接不会提升原始行情质量。

检查连接：`.\.venv\Scripts\python.exe remote.py status`。测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。远程保护实现依据 [Tailscale Serve 官方说明](https://tailscale.com/docs/features/tailscale-serve)。
