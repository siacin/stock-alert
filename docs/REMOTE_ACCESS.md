# 可选：手机访问电脑版后台

纯电脑版用户无需安装 Tailscale。这个功能不是安卓 APK，也不把网站公开到互联网。

## 首次配对

1. 电脑先启动 `start.cmd`。
2. 从 [Tailscale 官网](https://tailscale.com/download/windows)安装客户端。
3. 双击 `remote.cmd`，在官方页面完成登录及 Serve/HTTPS 授权。等待超时后重新运行向导即可。
4. 手机安装官方 Tailscale，登录同一个账号并开启连接。
5. 在电脑网页的“手机连接”中复制私有 HTTPS 地址，用手机浏览器打开。可以添加到主屏幕。

HTTPS 证书中的设备域名会进入公开证书透明度日志，但页面仍只允许获授权的设备访问。向导只配置私有 **Serve**，不配置公网 **Funnel**，不会覆盖其他已有代理配置。

## 使用与关闭

- 电脑及软件必须持续运行，手机与电脑都需要连上 Tailscale。
- 自选、监控规则和状态由电脑统一保存。网页前台约每 3 秒同步配置，后台切回前台时刷新；未保存草稿不会同步。
- 修改监控规则前先停止监控，保存后再启动；两端同时保存时会提示版本冲突。
- Agent API 地址与密钥只能在电脑本机管理；手机可以调用已配置的分析并查看共享结果。
- 电脑页面点击“手机连接 → 关闭远程授权”会立即阻止手机后续请求，本机不受影响。
- 如需同时移除本软件的私有代理，在项目目录执行：

```powershell
.\.venv\Scripts\python.exe remote.py disable
```

查看状态：

```powershell
.\.venv\Scripts\python.exe remote.py status
```

本机管理端口仅监听 `127.0.0.1:8765`；带身份校验的远程代理端口仅监听 `127.0.0.1:8766`。不要绑定公网地址或添加路由器端口转发，也不要将其他代理指向本机管理端口。

## 无法连接时

确认电脑未休眠、后台仍在运行、两端 Tailscale 已连接且账号一致。确认打开的是向导生成的 `https://…ts.net/` 地址，不是手机自己的 `127.0.0.1`。检查 8766 是否被其他程序占用，或是否在电脑页面关闭了远程授权。

软件不内置安卓后台常驻或系统推送；锁屏时应视为可能无法及时提醒。
